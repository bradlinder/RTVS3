Radio & TV Segmenter v3.10.9-beta Build Notes

Windows builds produce the main desktop GUI and a dedicated `workers\prs_worker.exe`
AI worker, sharing a unified runtime. Build-time self-tests smoke-test PyTorch/torch._C,
CTranslate2, Silero VAD, and WeSpeaker ONNX (`wespeakerruntime`). Heavy machine translation
(CTranslate2 / Hugging Face MarianMT & NLLB) is isolated within `plugins/translation/`.

===============================================================================
Radio & TV Segmenter - Build & Environment Setup Instructions
===============================================================================

1. SYSTEM PREREQUISITES
-------------------------------------------------------------------------------
- Python 3.10 to 3.12+ (64-bit recommended)
- Node.js 18+ (only required for running the zero-dependency `node server.js` status preview)
- FFmpeg installed and accessible in your system PATH (or in the app root directory)
- Git

2. HARDWARE ACCELERATION (NVIDIA CUDA - WINDOWS)
-------------------------------------------------------------------------------
The core application, speaker diarization (WeSpeaker ONNX), and machine translation
(CTranslate2 INT8) are CPU-first and CUDA-free across all operating systems.
On Windows systems with an NVIDIA GPU, an isolated CUDA environment for Whisper
transcription can be downloaded on demand directly from Settings > GPU Acceleration Settings...
No manual PyTorch or CUDA driver installation is required in the base environment.

3. PYTHON VIRTUAL ENVIRONMENT & DEPENDENCIES
-------------------------------------------------------------------------------
Create and activate your virtual environment:

  Windows:
    python -m venv venv
    venv\Scripts\activate

  Linux / macOS:
    python3 -m venv venv
    source venv/bin/activate

Install core application requirements:
    pip install -r installer/requirements.txt
    pip install -r requirements-build.txt

Heavy machine translation (OPUS-MT / Transformers) runs in an isolated,
on-demand runtime managed automatically by the application (see plugins/translation).

4. AI STUDIO WEB STATUS PREVIEW (ZERO-DEPENDENCY NODE.JS)
-------------------------------------------------------------------------------
The web preview container runs a zero-dependency Node.js HTTP status card (`node server.js` on port 3000).
Do NOT run `npm install` or scaffold React/Vite bundles. To restore or sync version metadata:
    python preview_manager.py --sync

5. RUNNING THE APPLICATION LOCALLY
-------------------------------------------------------------------------------
Execute:
    python RadioTVSegmenter.py

6. PACKAGING, STANDALONE BUILDS & RELEASE DISTRIBUTION
-------------------------------------------------------------------------------
- Windows:
    Run build_windows.bat or compile RadioTVStorySegmenter.iss using Inno Setup.
- macOS:
    Run ./build_macos.sh
- Linux:
    Run ./build_linux.sh or ./installer/Linux/build_deb.sh

Note on Releases:
Distribute all built installers, binaries, and source snapshot archives via
GitHub Releases. Avoid committing .zip or archive files directly into git history
to prevent repository bloat.
