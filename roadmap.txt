================================================================================
RADIO & TV STORY SEGMENTER - DEVELOPMENT ROADMAP & TECHNICAL SPECIFICATION
================================================================================
This document outlines the architectural roadmap and implementation specifications
for future versions of the Radio & TV Story Segmenter. Adapted from best-in-class
heuristics, modular runtime architectures, and timeline serialization algorithms.

--------------------------------------------------------------------------------
ROADMAP MAINTENANCE POLICY: N-1 SLIDING-WINDOW & STATUS TRACKING
--------------------------------------------------------------------------------
- The roadmap maintains a rolling window: it displays the current/immediate past
  release ($N-1$) for baseline context, followed by active upcoming development
  milestones ($N$, $N+1$).
- Status Notation Policy (Modeled after Social Digest):
  * All milestones and feature items are annotated with explicit progress indicators:
    - [x] Completed item / feature
    - [-] In-progress item / active development
    - [ ] Planned / not started item
  * When work commences on an item, mark it immediately as [-] [IN-PROGRESS].
  * Mark an item as [x] [COMPLETED] when implementation is finalized, upon user
    confirmation, or inferred when development transitions to another part of the roadmap.
- When a new version is built, its completed specifications are recorded, and any
  versions older than $N-1$ are pruned to keep the document focused and actionable.
- Whenever any code change, bug fix, packaging adjustment, or feature refinement is
  made during a release cycle, it MUST be recorded immediately in the current release
  section of roadmap.txt and CHANGELOG.md (even if it occurs after the initial version
  number bump).

1. PREVIOUS RELEASE: REAPER RPP CLEAN HEADER, NATIVE FADES, COLOR-CODED REGIONS & SCOPE-AWARE SPLITS [x] [COMPLETED in v3.8.9-beta.19]
================================================================================

[x] 1.1 Eliminated REAPER Project Load Warnings (`export/timeline.py`)
--------------------------------------------------------------------------------
- Stripped obsolete and problematic tokens (`MIXERSLIDERS` and `PLAYREC`) from the Cockos REAPER `.rpp` generator, ensuring exported projects open cleanly without warning dialogs or token load errors across REAPER installations.

[x] 1.2 Native REAPER Fades & Curve Shape Mapping (`export/timeline.py`)
--------------------------------------------------------------------------------
- Connected story `fade_in`, `fade_out`, and `fade_curve` parameters directly to REAPER's `<ITEM` chunk with second-precision durations and native curve shape index mapping (`linear` -> 0, `exponential` -> 1, `logarithmic` -> 2, `s_curve` -> 3).
- Manually adjusted RTVS fades now render exact visual fade ramps and interactive handles on media items in REAPER.

[x] 1.3 Color-Coded Story Regions & Track Items Matching RTVS Palette (`export/timeline.py`)
--------------------------------------------------------------------------------
- Generates Cockos REAPER paired region markers (`MARKER <id> <start> "<title>" 1 <color> 1 B {GUID} 0` and `MARKER <id> <end> "" 1`) across the project ruler, accurately marking each story boundary.
- Regions and track media items are color-coded using REAPER's `0x1000000 | 0x1RRGGBB` format (`COLOR <color> B`) using the exact harmonized accessible 8-color story palette from RTVS (`#2563eb`, `#d97706`, `#059669`, `#7c3aed`, `#e11d48`, `#0d9488`, `#4f46e5`, `#db2777`).

[x] 1.4 Clean Split Division with Unlabelled Non-Story Audio (`export/timeline.py`, `project_export.py`)
--------------------------------------------------------------------------------
- Non-story sections (audio before, between, or after stories) are cleanly split without artificial placeholder labels like "Interstitial Gap" or "Intro / Pre-Story" (`NAME ""`), keeping the episode continuous without cluttering item names.
- Story sections and unselected stories always retain their authentic story titles and segment identity.
- Full Episode: Generates continuous timeline coverage spanning 0:00 to the total episode duration with pre-splits separating stories and unlabelled non-story audio.
- All Stories / Selected Stories: Generates isolated story cuts on a dedicated track with non-story audio excluded.
- Full Episode & All Stories: Generates a multi-track DAW layout with Track 1 ("Full Episode (Splits)") and Track 2 ("Story Cuts"), accompanied by REAPER color-coded region markers.

[x] 1.5 Multi-DAW Scope & Split Parity (`export/timeline.py`)
--------------------------------------------------------------------------------
- Extended continuous full-episode split generation and unlabelled non-story audio handling across Final Cut Pro XML, DaVinci Resolve, AAF, Hindenburg, and Samplitude EDL.

[x] 1.6 File Menu Redundancy Cleanup (`ui_layout.py`)
--------------------------------------------------------------------------------
- Removed the redundant `Export Timeline / DAW...` action from the File menu, directing timeline export workflows cleanly into the Unified Export Center dialog.

[x] 1.7 Diagnostic Suite Coverage (`test_runner.py`)
--------------------------------------------------------------------------------
- Added test assertions in `test_runner.py` verifying header hygiene, Full Episode split continuity with unlabelled non-story sections, paired color-coded regions, and curve fade mapping.

[x] 1.8 Synchronous Version Bump
--------------------------------------------------------------------------------
- Synchronized all 10 project locations to v3.8.9-beta.19

2. CURRENT RELEASE: STATION VOICE PROFILES LIBRARY, MULTI-TIER MIPMAPPED PEAK CACHE & SPEED-LISTENING PROOFREADING ENGINE [x] [COMPLETED in v3.9.0-beta.2]
================================================================================

[x] 2.1 Persistent Station Voice Profiles Library ("Manage Voice Profiles...") (`speaker_profiles.py`, `transcript_story.py`, `speaker_dialogs.py`, `ui_layout.py`)
--------------------------------------------------------------------------------
- Standalone persistent library: `StationVoiceProfileStore` saving normalized 256-dimensional acoustic embedding vectors, sample counts, timestamps, and notes in `voice_profiles.json`.
- Manage Voice Profiles Dialog: `ManageVoiceProfilesDialog` for browsing, renaming, auditing, matching against active project segments, creating profiles from active turns, and importing/exporting profiles.
- Integrated into `Tools -> Voice Profile Tools -> Manage Voice Profiles...` and the Speaker Manager dialog.

[x] 2.2 Automatic Diarization Matching & Preference Configuration (`processing.py`, `playback_preferences.py`, `RadioTVSegmenter.py`)
--------------------------------------------------------------------------------
- Automatically matches newly detected speaker clusters against stored voice profiles above a configurable cosine similarity threshold (default 78%).
- Added options in Preferences (*Story Detection & Diarization*) allowing users to enable or disable voice profiles entirely and adjust the auto-match similarity threshold (50% to 99%).

[x] 2.3 Multi-Tier Mipmapped Waveform Peak Cache (LOD Rendering) (`background_workers.py`, `timeline_widgets.py`)
--------------------------------------------------------------------------------
- Upgraded `.peaks` binary file format to Version 2, storing base 1x peaks and precomputed 4x, 16x, 64x mipmapped downsampled levels directly on disk in `.cache/peaks/` and appdata.
- Delivers locked 60fps scrubbing and instantaneous loading on multi-hour recordings while preserving transparent backward compatibility with Version 1 caches.

[x] 2.4 Speed-Listening "Type-to-Correct" Proofreading Engine (`transcript_editor.py`, `playback_preferences.py`, `ui_layout.py`)
--------------------------------------------------------------------------------
- Added pitch-preserving playback speed selector (0.75x, 1.0x, 1.25x, 1.5x, 1.75x, 2.0x) to transport controls and Preferences via native WSOLA.
- Implemented `Tab` key shortcut to pause playback, switch to editing mode, and place cursor directly on active word for typing. Pressing `Tab` again cleanly resumes playback with configurable pre-roll rewind (default 0.5s).

[x] 2.5 Diagnostic Verification Suite (`test_runner.py`)
--------------------------------------------------------------------------------
- Test assertions in `test_runner.py` verifying voice profile store serialization, Version 2 mipmapped `.peaks` cache reading/writing, speed-listening rate changes, and pre-roll context settings.

[x] 2.6 Synchronous Version Bump
--------------------------------------------------------------------------------
- Synchronized all 10 project locations to v3.9.0-beta.2
