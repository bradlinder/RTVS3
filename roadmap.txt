This document outlines the architectural roadmap and implementation specifications
for future versions of the Radio & TV Story Segmenter. Adapted from best-in-class
heuristics, modular runtime architectures, and timeline serialization algorithms.

--------------------------------------------------------------------------------
ROADMAP MAINTENANCE POLICY: N-1 SLIDING-WINDOW & STATUS TRACKING
--------------------------------------------------------------------------------
- The roadmap maintains a rolling window: it displays the current/immediate past
  release ($N-1$) for baseline context, followed by active upcoming development
  milestones ($N$, $N+1$).
- Status Notation Policy (Modeled after Social Digest):
  * All milestones and feature items are annotated with explicit progress indicators:
    - [x] Completed item / feature
    - [-] In-progress item / active development
    - [ ] Planned / not started item
  * When work commences on an item, mark it immediately as [-] [IN-PROGRESS].
  * Mark an item as [x] [COMPLETED] when implementation is finalized, upon user
    confirmation, or inferred when development transitions to another part of the roadmap.
- When a new version is built, its completed specifications are recorded, and any
  versions older than $N-1$ are pruned to keep the document focused and actionable.
- Whenever any code change, bug fix, packaging adjustment, or feature refinement is
  made during a release cycle, it MUST be recorded immediately in the current release
  section of roadmap.txt and CHANGELOG.md (even if it occurs after the initial version
  number bump).

CORE ARCHITECTURAL INVARIANTS
================================================================================
- Core modules must NEVER import from plugins/.
- Heavy translation runtimes must remain isolated inside plugins/translation/.
- Speaker diarization uses wespeakerruntime as the primary ONNX embedding engine.
- Real-time progress updates with percentage, status messages, and estimated time.
- Diagnostic logs written to OS standard logging locations.
- Offline-first architecture: core processing functions locally without internet.
- 0 MB Default GPU Footprint: Base installer contains 0 MB of CUDA bloat; GPU features are purely optional and provisioned on demand.

1. PREVIOUS RELEASE: WINDOWS UPDATER SPAWN FIX & BUTTON LABELING (Completed in v3.2.14)
================================================================================

[x] 1.1 WINDOWS DETACHED PROCESS EXECUTION & UAC ELEVATION
----------------------------------------------------------
- Enhanced `launch_and_install` in `updater.py` with multi-tier execution on Windows using `subprocess.Popen(..., creationflags=DETACHED_PROCESS | CREATE_NEW_PROCESS_GROUP)`.
- Added 64-bit typed `ctypes.windll.shell32.ShellExecuteW` fallback with `"runas"` UAC elevation verb and `os.startfile`.

[x] 1.2 GUARANTEED PROCESS EXIT & FILE LOCK TEARDOWN
-----------------------------------------------------
- Implemented window teardown and guaranteed exit (`os._exit(0)`) in `_install_and_restart` to release all file locks immediately so Inno Setup can overwrite binaries cleanly.

[x] 1.3 QT ACCELERATOR AMPERSAND ESCAPING
-----------------------------------------
- Properly escaped accelerator ampersands as `"Install && Restart"` in Qt button declarations to ensure text renders cleanly as **"Install & Restart"**.

2. CURRENT RELEASE: ROBUST TRANSLATION CANCELLATION & DIARIZATION MODEL MANAGEMENT (Completed in v3.2.15)
================================================================================

[x] 2.1 MULTI-TIER TRANSLATION CANCELLATION
-------------------------------------------
- Updated `cancel_current_process` and `confirm_stop_processing_for_media_change` in `processing.py` to check `translation_process`, `translation_thread`, `_translation_env_thread`, and `_translation_env_worker`.
- Replaced error `[PROCESS] No cancellable process is currently running` with deterministic termination of active translation runs.

[x] 2.2 ISOLATED TRANSLATION WORKER TEARDOWN & CLEANUP
------------------------------------------------------
- Enhanced `stop_translation_worker` in `translation.py` to cancel worker threads, kill subprocesses, disconnect pending signals, unlink temporary IPC request JSON files, and restore UI controls to idle.

[x] 2.3 EXPORT STATE TRACKING ISOLATION
---------------------------------------
- Added `is_exporting` state flag to `project_export.py` so background task cancellation does not trigger spurious `[EXPORT] Cancel requested by user` log lines.

[x] 2.4 SPEAKER DIARIZATION MODEL MANAGEMENT & PURGING
------------------------------------------------------
- Replaced static informational message with interactive model management for Speaker Diarization (WeSpeaker ResNet34 ONNX Voice Embedding).
- Added genuine directory inspection (`~/.wespeaker`, `models/wespeaker`), live size calculation, background download worker (`DiarizationModelInstallWorker`), individual model removal, and complete cache purging.
