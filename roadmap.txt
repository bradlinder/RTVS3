This document outlines the architectural roadmap and implementation specifications
for future versions of the Radio & TV Story Segmenter. Adapted from best-in-class
heuristics, modular runtime architectures, and timeline serialization algorithms.

--------------------------------------------------------------------------------
ROADMAP MAINTENANCE POLICY: N-1 SLIDING-WINDOW & STATUS TRACKING
--------------------------------------------------------------------------------
- The roadmap maintains a rolling window: it displays the current/immediate past
  release ($N-1$) for baseline context, followed by active upcoming development
  milestones ($N$, $N+1$).
- Status Notation Policy (Modeled after Social Digest):
  * All milestones and feature items are annotated with explicit progress indicators:
    - [x] Completed item / feature
    - [-] In-progress item / active development
    - [ ] Planned / not started item
  * When work commences on an item, mark it immediately as [-] [IN-PROGRESS].
  * Mark an item as [x] [COMPLETED] when implementation is finalized, upon user
    confirmation, or inferred when development transitions to another part of the roadmap.
- When a new version is built, its completed specifications are recorded, and any
  versions older than $N-1$ are pruned to keep the document focused and actionable.
- Whenever any code change, bug fix, packaging adjustment, or feature refinement is
  made during a release cycle, it MUST be recorded immediately in the current release
  section of roadmap.txt and CHANGELOG.md (even if it occurs after the initial version
  number bump).

1. PREVIOUS RELEASE: COMPREHENSIVE CLOUD & LOCAL BACKUP & RESTORE SYSTEM [x] [COMPLETED in v3.8.0-stable]
================================================================================

[x] 1.1 Unified State Serialization (`backup_manager.py`)
--------------------------------------------------------------------------------
- Developed `create_backup_payload` bundling persistent preferences (`QSettings`), custom keyboard shortcut reassignments (`shortcuts_manager.py`), glossary / terminology entries (`terminology.py`), installed AI model metadata (`runtime_manager.py`), and plugin toggle states into a portable `.rtvs-settings` payload.
- Integrated deterministic SHA-256 cryptographic checksum calculation over canonical JSON representation to guarantee complete data fidelity and prevent tamper/corruption errors.

[x] 1.2 Manual Local Backup & Restore Center (`backup_manager.py`, `project_lifecycle.py`, `ui_layout.py`)
--------------------------------------------------------------------------------
- Built `BackupRestoreDialog` modal window equipped with `make_dialog_maximizable(self)` and clean desktop styling.
- Bound to **File > Backup & Restore...** (`Ctrl+Shift+U`) and **Settings > Backup & Restore Settings...**.
- Local Archive tab provides active configuration metrics (key counts, shortcuts, glossary entries), 1-click `.rtvs-settings` creation, and guided archive restoration with pre-flight summary confirmation and live in-memory reload.

[x] 1.3 1-Click Google Drive Cloud Restore & Backup (`backup_manager.py`, `plugins/gdocs/auth.py`)
--------------------------------------------------------------------------------
- Reused `GoogleDocsAuthManager` with existing `https://www.googleapis.com/auth/drive.file` OAuth scope without requiring redundant authentication setup.
- Implemented `upload_cloud_backup` utilizing Drive API v3 multipart upload protocol with timestamped backup archives and SHA-256 metadata descriptions.
- Implemented `list_cloud_backups` and `restore_cloud_backup` with automated SHA-256 validation prior to applying restored states.

[x] 1.4 Tri-Location Transcript Milliseconds Toggle & Persistent View Menu (`ui_layout.py`, `export/dialog.py`, `playback_preferences.py`)
--------------------------------------------------------------------------------
- Sub-second millisecond precision toggle accessible in View menu, Unified Export window, and Preferences dialog.
- PersistentMenu subclass keeps View menu open during toggle operations for seamless multi-selection.
