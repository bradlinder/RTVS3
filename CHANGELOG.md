# Changelog

## v3.9.61-beta
- **Installed Windows Drag-and-Drop & UIPI Elevation Bridge (`win32_dnd.py`, `RadioTVSegmenter.py`, `ui_layout.py`, `installer/Windows/RadioTVStorySegmenter.iss`)**:
  - **Dual-Layer Win32 Native Drag-and-Drop Bridge (`win32_dnd.py`, `RadioTVSegmenter.py`)**: Implemented a dedicated native message filter bridge using `QAbstractNativeEventFilter` that intercepts Win32 `WM_DROPFILES` (`0x0233`) and queries dropped file paths via `DragQueryFileW`. This provides dual redundancy alongside Qt's OLE layer, ensuring file drops work even when Windows UIPI (User Interface Privilege Isolation) restricts OLE communication under elevation or strict integrity boundaries.
  - **Early Single-Threaded Apartment (STA) COM Initialization (`win32_dnd.py`)**: Added `init_ole_sta()` calling `OleInitialize()` at the very start of application boot on Windows, guaranteeing COM is initialized in STA mode before native machine learning C-extensions can set MTA mode.
  - **UIPI Window Message Whitelisting (`win32_dnd.py`)**: Wires `ChangeWindowMessageFilterEx` on the main window's native `HWND` for `WM_DROPFILES` (`0x0233`), `WM_COPYDATA` (`0x004A`), and `WM_COPYGLOBALDATA` (`0x0049`) with `MSGFLT_ALLOW`, paired with `DragAcceptFiles(hwnd, True)`.
  - **Child Widget Drag Event Suppression Fix (`ui_layout.py`)**: Removed `central_widget.setAcceptDrops(True)` on the plain layout container. In Qt, enabling drops on an un-overridden `QWidget` causes it to call `event.ignore()` and actively suppress drag event bubbling to parent and canvas handlers; removing it restores natural event routing to `TimelineCanvas` and `MainWindow`.
  - **Shortcut Working Directory Specification (`RadioTVStorySegmenter.iss`)**: Configured explicit `WorkingDir: "{app}"` for both desktop and start menu shortcuts generated by the Inno Setup installer.

## v3.9.60-beta
- **Empty Project Close & Save Prompt Bypass (`project_state_mixin.py`, `media_batch.py`, `project_lifecycle.py`, `project_export.py`, `diagnostic_cloud_and_system_tests.py`)**:
  - **Workspace State Inspection (`is_project_empty()`)**: Added `is_project_empty()` to `ProjectStateMixin` to verify whether the workspace contains loaded audio (`audio_file`), an associated project file (`project_file`), transcript text/segments (`transcript`), or defined stories (`stories`).
  - **Silent Media Ingestion on Blank Canvas**: Updated `prepare_for_new_media()` in `media_batch.py` so opening or dragging an audio file into an empty workspace proceeds immediately without prompting *"The current project has unsaved changes. Would you like to save it before closing?"*.
  - **Silent Project Reset & Clean State Guarantee**: Updated `close_project()` and `load_project_file()` in `project_lifecycle.py` and `closeEvent()` in `project_export.py` to bypass confirmation dialogs when the workspace is empty, and ensured `self.project_dirty = False` is explicitly reset on project close so subsequent file operations always start with a clean state.
