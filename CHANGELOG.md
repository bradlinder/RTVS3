# Changelog

## v3.10.22-beta
- **Checkable Full Episode Option in Export Dialog Custom Selection Sidebar (`export/story_selector.py`, `export/dialog.py`, `export_dialogs.py`, `export_story_pipeline.py`, `export_media_clipper.py`, `plugins/wordpress/wp_post_builder.py`, `plugins/wordpress/wp_tab_widget.py`, `plugins/wordpress/export_destination.py`, `plugins/wordpress/manifest.json`, `plugins/youtube/export_destination.py`, `plugins/youtube/manifest.json`, `diagnostics/export_wordpress_core.py`)**:
  - **Full Episode Toggle in Export Sidebar (`export/story_selector.py`, `export/dialog.py`)**:
    - Added a bold, checkable **Full Episode** row at the top of `ExportStorySelectorSidebar` (unchecked by default so plain selected-segments workflows stay unchanged) and clarified the scope label to **Selected Stories / Custom Selection** (preserving the `"selected_stories"` scope key).
    - Updated **Select All**, **Clear**, `(X of Y)` count, empty-selection validation, and `get_result()` (`include_full_episode`) so users can export **Full Episode + any subset of segments** (or Full Episode alone) in a single pass without altering main-window timeline story selection.
  - **Cross-Destination Support & WordPress Parent/TOC Linking (`export_dialogs.py`, `export_story_pipeline.py`, `export_media_clipper.py`, `plugins/wordpress/*.py`, `plugins/youtube/export_destination.py`)**:
    - Wired `include_full_episode` across WordPress (`build_wp_post_items()`, `select_full_episode()`, and `execute_export()` with automatic parent-episode cross-linking and filtered story TOC), Local Files (`export_full_and_all_stories(..., story_indices=...)` / `export_full_episode()`), Timeline/DAW interchange, and YouTube Video Publisher, repackaged `wordpress` and `youtube` addons (`3.10.22-beta`), and added live dialog regression tests.

## v3.10.21-beta
- **YouTube-Source WordPress Featured Image Defaults & Individual Segment YouTube Embed Inheritance (`plugins/wordpress/wp_thumbnail_defaults.py`, `plugins/wordpress/wp_thumb_ui.py`, `plugins/wordpress/wp_post_builder.py`, `plugins/wordpress/wp_ui_builder.py`, `plugins/wordpress/wp_tab_widget.py`, `plugins/wordpress/wp_workers.py`, `plugins/wordpress/youtube_embed.py`, `plugins/wordpress/export_destination.py`, `plugins/wordpress/manifest.json`, `plugins/youtube/yt_import_dialog.py`, `plugins/youtube/manifest.json`, `diagnostics/export_wordpress_core.py`, `diagnostics/system_runtime_tests.py`)**:
  - **Fix Missing YouTube Video Embed on Individual Segment Pages (`wp_thumbnail_defaults.py`, `wp_post_builder.py`, `youtube_embed.py`, `export_destination.py`)**:
    - Fixed `build_wp_post_items()` and `execute_export()` so individual stories created after importing a YouTube video (or stored with passive empty legacy metadata) automatically inherit the project's YouTube URL, video ID, story-timestamp start setting, stop-at-end preference, and placement whenever `youtube_apply_all` is enabled, while respecting explicit per-story clearing (`youtube_explicitly_cleared`).
  - **Default Featured Images for YouTube-Source Full Episode & Segments (`wp_thumbnail_defaults.py`, `wp_thumb_ui.py`, `wp_ui_builder.py`, `wp_tab_widget.py`, `wp_workers.py`, `wp_post_builder.py`, `export_destination.py`, `yt_import_dialog.py`)**:
    - Added a **YouTube default thumbnail** option in the WordPress Featured Image controls and defaulted YouTube-source **Full Episode** posts to the YouTube page's default thumbnail (downloaded with `maxresdefault.jpg` → `thumbnail_url` → `sddefault.jpg` → `hqdefault.jpg` fallback, validated, and atomically cached in the managed remote media cache via non-blocking `YouTubeThumbnailFetchWorker`), while keeping **Grab frame from video**, **Select custom image file...**, and **None** fully selectable.
    - Defaulted YouTube-source **individual segments** to **Grab frame from video** at a representative timestamp strictly inside `[story.start, story.end]`, auto-previewing when selected and materializing frames/thumbnails on demand during `execute_export()` even for segments whose Media tab was never opened, while preserving explicit user choices (`featured_image_user_set`) and shrinking `wp_tab_widget.py` (`991` → `935` lines).
    - Preserved `thumbnail_url` in `remote_media_source` during YouTube import, updated `[YT, Img]` sidebar indicators/tooltips, repackaged `wordpress.rtvs-addon` and `youtube.rtvs-addon` (`3.10.21-beta`), and added offline-safe end-to-end diagnostic tests.
