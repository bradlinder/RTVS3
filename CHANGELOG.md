# Changelog

## v3.10.27-beta
- **Fast Project-Open Thumbnail Loading (Async + Local SMB Cache), Keyframe-Accelerated Thumbnails with Live Progress, Custom Selection Sidebar Parity, Click-to-Enlarge Featured Image & Scrollable Preferences (`thumbnail_workers.py`, `background_workers.py`, `media_batch.py`, `project_lifecycle.py`, `timeline_widgets.py`, `timeline_painter.py`, `export/story_selector.py`, `export/dialog.py`, `plugins/wordpress/wp_thumb_ui.py`, `plugins/wordpress/wp_ui_builder.py`, `plugins/wordpress/wp_tab_widget.py`, `plugins/wordpress/youtube_embed.py`, `plugins/wordpress/manifest.json`, `preferences_dialog.py`, `installer/build_tools/config.py`, `diagnostics/editor_story_ui_tests.py`, `diagnostics/export_wordpress_media.py`)**:
  - **Eliminate Project-Open Sluggishness & Network-Share Cache Freezes (`thumbnail_workers.py`, `background_workers.py`, `media_batch.py`, `project_lifecycle.py`, `timeline_widgets.py`)**:
    - Extracted video thumbnail caching and workers into dedicated `thumbnail_workers.py` (reducing `background_workers.py` below the 1,000-line ceiling and registering `thumbnail_workers` in PyInstaller `HIDDEN_IMPORTS`).
    - Added `is_network_path()` so projects on UNC/SMB network shares or mapped network drives store derived thumbnail and waveform peak caches in local `%LOCALAPPDATA%\RadioTVStorySegmenter\cache\` (with automatic one-time `.peaks` migration) instead of reading/writing hundreds of small files across the network.
    - Replaced per-file `exists()`/`stat()` loops in `read_video_thumbnail_cache()` with a single `os.scandir()` pass, added background `VideoThumbnailCacheLoader` decoding cached JPEGs into thread-safe `QImage`s off the GUI thread, deduplicated back-to-back `start_video_thumbnail_generation()` calls triggered by `load_project_file()` + `QMediaPlayer.durationChanged`, fixed the `VideoThumbnailWorker` cancel race via a process lock, and avoided reading `.rtvs` twice during startup `restore_last_opened()`.
  - **Faster Video Thumbnail Generation & Live Progress (`thumbnail_workers.py`, `media_batch.py`, `timeline_widgets.py`, `timeline_painter.py`)**:
    - Enabled FFmpeg `-skip_frame nokey` keyframe-only decoding on coarse/medium presets (`Standard` and `Detailed`) with automatic full-decode fallback if too few frames are produced.
    - Parsed FFmpeg `-progress pipe:1` (`out_time_us` / `out_time`) to stream live `%` progress onto both the timeline status banner and video thumbnail placeholder badge (`Generating video thumbnails (42%)...`).
  - **Custom Selection Sidebar Parity & Live Export Button Count (`export/story_selector.py`, `export/dialog.py`, `plugins/wordpress/youtube_embed.py`, `plugins/wordpress/wp_ui_builder.py`, `plugins/wordpress/wp_tab_widget.py`)**:
    - Visually muted unchecked rows in `ExportStorySelectorSidebar`, mirrored WordPress `[YT, Img]` / `[Pod]` / `[A]` badges and rich hover tooltips onto checked rows when WordPress is active, kept **Auto-fill All Excerpts** accessible beside **Generate from Story** whenever WordPress's internal post list is hidden under `Custom Selection`, and appended the live checked item count `(N)` to the primary Export button label under `Custom Selection`.
  - **Click-to-Enlarge WordPress Featured Image Preview (`plugins/wordpress/wp_thumb_ui.py`, `plugins/wordpress/wp_ui_builder.py`, `plugins/wordpress/wp_tab_widget.py`, `plugins/wordpress/manifest.json`)**:
    - Upgraded `wp_thumb_preview_label` to `ClickableThumbnailLabel` (pointing-hand cursor and tooltip when an image is loaded) opening a resizable `FeaturedImageLightboxDialog` showing the full-resolution YouTube thumbnail, grabbed video frame, or custom image with pixel dimensions, and repackaged `wordpress.rtvs-addon` (`3.10.27-beta`).
  - **Scroll-Area Audit Across Remaining Preferences Tabs (`preferences_dialog.py`)**:
    - Wrapped all remaining non-table Preferences tabs (General, Audio Settings, Updates & GitHub, AI Models, GPU Acceleration, External Audio & Video Editors, Detection, Batch Processing, Cleanup Data, WordPress, and YouTube) in borderless `QScrollArea`s (`widgetResizable=True`) so no controls clip or overlap at minimum window height.

## v3.10.26-beta
- **Duration-Scaled Per-Minute Thumbnail Density Presets, Anywhere-on-Timeline Regenerate Menu & Synchronized Shortcuts/User Guides (`background_workers.py`, `media_batch.py`, `preferences_tabs_media.py`, `timeline_context_menus.py`, `shortcuts/schema.py`, `user_guide_dialog.py`, `docs/guides/*.md`, `embedded_guides.py`, `README.md`, `diagnostics/editor_story_ui_tests.py`)**:
  - **4-Tier Duration-Scaled Per-Minute Thumbnail Density (`background_workers.py`, `media_batch.py`, `preferences_tabs_media.py`)**:
    - Replaced fixed thumbnail frame counts with four duration-scaled presets labeled by rate per minute: **Standard (2 per min, 16–180)**, **Detailed (4 per min, 24–300)**, **High (8 per min, 36–480)**, and **Extra High (16 per min, 48–960)**.
    - Updated `VideoThumbnailWorker` to extract `240px`-wide frames (`~50%` lower RAM footprint while staying sharp on HiDPI timelines) using 4-digit filenames (`thumb_%04d.jpg`) and distinct per-count cache directories.
  - **Right-Click Anywhere on Timeline for Regeneration (`timeline_context_menus.py`)**:
    - Exposed **Regenerate Waveform** and the 4-tier checkable **Regenerate Video Thumbnails** submenu when right-clicking anywhere on the timeline—including inside already-assigned segments/stories—not only on empty space.
  - **Synchronized Keyboard Shortcuts, Built-In Guides & README (`shortcuts/schema.py`, `user_guide_dialog.py`, `docs/guides/*.md`, `embedded_guides.py`, `README.md`)**:
    - Updated `detect_stories` and `regen_thumbnails` descriptions in `shortcuts/schema.py` and `README.md`, added the **Right-Click Timeline** control note to `user_guide_dialog.py`, updated all five relevant user guides (`getting_started_and_workflow.md`, `wordpress_exporting.md`, `export_formats.md`, `youtube_features.md`, `video_shows_and_youtube_publishing.md`) for `Custom Selection`, YouTube-source WordPress defaults/embed inheritance, two-step Detect Segments overrides, Audio Fades 2×2 curve layout, and per-minute thumbnail density, and mirrored them verbatim into `embedded_guides.py`.
