# Changelog

## v3.10.39-beta
- **Cache Manager `os.scandir()` Optimization & `File > Open Document...` Polish (`cache_manager.py`, `media_batch.py`, `prs_shared.py`, `installer/build_tools/config.py`, `diagnostics/cloud_storage_tests.py`, `diagnostics/batch_export_tests.py`)**:
  - **Fast `os.scandir()` Cache Scanning & Purging (`cache_manager.py`)**: Replaced recursive `Path.rglob()`, double `resolve()`, and 6 separate `%TEMP%` `glob()` passes with iterative `os.scandir()` walkers (`_scan_tree_scandir`, `_purge_tree_scandir`) and a single `%TEMP%` pass via `_is_temp_audio_workfile()`; skipped network/UNC paths before probing disk; aligned `ClearCacheDialog` scan/purge scope; and added `cache_workers` to PyInstaller `HIDDEN_IMPORTS` (`installer/build_tools/config.py`).
  - **`File > Open Document...` Polish (`media_batch.py`, `prs_shared.py`)**: Unified `open_document()` to delegate to `open_document_path()` with full media/timeline/thumbnail/metadata reset, added `is_pdf_reading_available()` to omit PDF filters when unavailable and give a clean frozen-app error, and updated `HTMLTextParser` to strip `<script>`/`<style>`/`<noscript>` and preserve block line breaks.
  - **Expanded Diagnostic Coverage (`diagnostics/cloud_storage_tests.py`, `diagnostics/batch_export_tests.py`)**: Added UNC-skip and `_is_temp_audio_workfile` assertions to Test #55 and HTML parsing / `open_document_path()` reset assertions to Test #39.

## v3.10.38-beta
- **Phase 2 Hardening: Media-Only Batch Processing & Async `ClearCacheDialog` Background Workers (`batch_dialog.py`, `media_batch.py`, `cache_workers.py`, `cache_manager.py`, `RadioTVSegmenter.py`, `processing.py`, `scripts/dev_check.py`, `diagnostics/batch_export_tests.py`, `diagnostics/cloud_storage_tests.py`)**:
  - **Media-Only Batch Processing & Dead Document Stub Removal (`batch_dialog.py`, `media_batch.py`, `RadioTVSegmenter.py`, `processing.py`, `scripts/dev_check.py`)**: Added canonical `BATCH_SUPPORTED_MEDIA_EXTENSIONS`, `is_supported_batch_media()`, and `collect_batch_media_paths()` helpers; updated `BatchProcessingDialog` prompt, file picker filter, and folder drop handling to accept only audio/video media files and report skipped non-media files; removed the dead `_batch_next_document()` / `_batch_document_error()` / `batch_document_queue` stub and `media_batch.py` allowlist entry from `scripts/dev_check.py`.
  - **Async `ClearCacheDialog` Scan & Purge Workers (`cache_workers.py`, `cache_manager.py`)**: Added `CacheScanWorker`, `CachePurgeWorker`, and `detach_cache_worker()` in `cache_workers.py` with cooperative `cancel_check` support in `get_cache_disk_usage()` / `purge_caches()`, moving disk scanning and cache purging off the Qt main GUI thread with busy-state controls, re-entrancy guards, main-thread `QSettings` collection, and safe `closeEvent`/`reject`/`accept` teardown.
  - **Expanded Diagnostic Coverage & CLI Qt Teardown (`diagnostics/batch_export_tests.py`, `diagnostics/cloud_storage_tests.py`)**: Updated Test #39 to verify media-only recursive folder filtering and dead document stub removal, and expanded Test #55 to verify `cancel_check` short-circuiting and `CacheScanWorker`/`CachePurgeWorker`/`ClearCacheDialog` async execution.
