# Changelog

## v3.10.36-beta
- **Eliminate Diagnostic Window Flashes & `libpng` / Null-`QPixmap` Console Errors (`plugins/wordpress/wp_thumb_ui.py`, `plugins/wordpress/pub_date_picker.py`, `preferences_dialog.py`, `diagnostics/export_wordpress_media.py`, `diagnostics/export_wordpress_upload.py`, `diagnostics/editor_story_ui_tests.py`)**:
  - **Null-`QPixmap` Guard & Valid Test PNGs (`plugins/wordpress/wp_thumb_ui.py`, `diagnostics/export_wordpress_media.py`, `diagnostics/export_wordpress_upload.py`)**: Guarded `set_preview_pixmap()` against `pix.isNull()` before calling `.scaled()`, and replaced truncated 8-byte fake PNG headers in WordPress media/upload tests with a valid 1×1 PNG, eliminating `libpng error: Read Error` and `QPixmap::scaled: Pixmap is a null pixmap` warnings.
  - **Silent Offscreen Diagnostic Windows (`plugins/wordpress/pub_date_picker.py`, `preferences_dialog.py`, `diagnostics/editor_story_ui_tests.py`)**: Set `Qt.WidgetAttribute.WA_DontShowOnScreen` (and guarded `raise_()` / `activateWindow()`) under `RTVS_TEST_MODE` for `_PublicationDatePickerPopup`, `PreferencesDialogMixin.open_preferences_dialog()`, and `play_tab` in Test #70, eliminating all visible window flashes during diagnostic runs.
  - **WordPress Plugin Catch-Up**: Bumped `plugins/wordpress/manifest.json` and repackaged `wordpress.rtvs-addon` to `3.10.36-beta`.

## v3.10.35-beta
- **Fix Frozen Diagnostic Failures (#51, #81) & Isolate Test #55 Cache/SMB/Models Stall (`plugins/manager_dialog.py`, `plugins/github_dialog.py`, `cache_manager.py`, `backup_manager.py`, `diagnostics/cloud_storage_tests.py`, `diagnostics/youtube_import_cache_tests.py`)**:
  - **Fix Test #51 (`Plugin Interface Sandbox Testing`) (`plugins/manager_dialog.py`, `plugins/github_dialog.py`, `diagnostics/cloud_storage_tests.py`)**: Defensively guarded `worker.isRunning()` with `callable(getattr(worker, "isRunning", None))` in `PluginManagerDialog._cleanup_workers()` and `GitHubPluginsDialog._cleanup_workers()`, and added `isRunning()` / `requestInterruption()` to `DummyUpdateWorker` so closing `PluginManagerDialog` in tests never raises `AttributeError`.
  - **Fix Test #81 (`Managed Remote Media Cache and Menu Shortcut Sync`) (`diagnostics/youtube_import_cache_tests.py`)**: Resolved `PROJECT_ROOT / "README.md"` and guarded the `README.md` text assertions with `is_file()` so frozen PyInstaller builds pass cleanly while still validating `embedded_guides`.
  - **Eliminate Test #55 (`Temporary Cache Management and Storage Inspection`) 288s Stall & Live-Cache Wipe (`cache_manager.py`, `backup_manager.py`, `diagnostics/cloud_storage_tests.py`)**: Added opt-out isolation parameters (`include_global_caches`, `include_settings_dirs`, `base_dir` in `cache_manager.py`; `models_dir_override` in `backup_manager.py`) and updated Test #55 to operate strictly inside temporary directories, eliminating real `QSettings`/SMB scans, unintended live cache deletion, and full AI model directory walks.
